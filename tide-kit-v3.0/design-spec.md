## 1. 로고

### 1-1. 구성
- **심볼(Wave mark):** 원 안에 파도선 두 줄이 있다. 할 일이 밀려왔다 빠지는 모습이다.
- **워드마크:** "Tide". Purple Purse를 굵게 보정한 뒤 아웃라인으로 만들었다. Purple Purse는 로고에만 쓰고 UI 글자에는 쓰지 않는다.
- **락업:** 심볼과 워드마크를 가로로 놓는다.
  - 심볼 지름은 워드마크 대문자 높이의 약 1.4배다.
  - 심볼과 워드마크 사이는 심볼 지름의 0.45배만큼 띄운다.

### 1-2. 로고 색
| 요소 | 기본 (밝은 배경) | 반전 (인디고·어두운 배경) |
|---|---|---|
| 심볼 원 | `secondary-600 #444892` | `primary-100 #F5F5F5` |
| 위 파도선 | **Logo Pink `#F1A8C5`** | `secondary-600 #444892` |
| 아래 파도선 | `primary-100 #F5F5F5`, 불투명도 85% | Logo Pink `#F1A8C5` |
| 워드마크 | `secondary-800 #272A5E` | `#FFFFFF` |

- **Logo Pink는 로고 안에서만 쓴다.** UI에는 쓰지 않고 컬러 체계에도 넣지 않는다.

### 1-3. 로고 종류
| 종류 | 언제 쓰나 |
|---|---|
| 가로 락업 (기본 / 반전) | 기본으로 이걸 쓴다 |
| 심볼 (기본 / 반전) | 공간이 좁을 때, 아바타·파비콘 |
| 워드마크 (기본 / 반전) | 심볼이 이미 근처에 있을 때 |
| 앱 아이콘 기본 | **48px 이상** |
| 앱 아이콘 작은 크기용 | **32px 이하**(파비콘, 작업 표시줄, 알림, 트레이). 파도선을 약 1.3배 굵게 하고 두 줄 간격을 벌려서 16px에서도 두 줄이 구분된다 |
| 메뉴바 아이콘 | 원 안의 파도를 비운 단색 템플릿. 라이트·다크 메뉴바에서 OS가 색을 바꾼다 |

### 1-4. 사용 규칙
- 로고 둘레에는 심볼 지름의 0.5배 이상 여백을 둔다.
- 최소 크기는 락업 높이 20px, 심볼만 쓸 때 16px이다.
- 하지 말 것: 워드마크를 다른 폰트로 바꾸기, 색 바꾸기, 그림자·외곽선 넣기, 비율 바꾸기.

## 2. 타이포그래피

### 2-1. 서체 역할

## 3. 컬러

### 3-1. 원칙
- **색은 주색과 보조색 두 가지뿐이다.**
  - **주색 Mist `#F5F5F5`:** 페이지 배경을 맡는다. 같은 회색 스케일에서 흰 카드, 글자, 테두리까지 나온다.
  - **보조색 Tide Indigo `#444892`:** 브랜드 컬러다. 사이드바, 버튼, 링크, 선택, '자동' 표시, 확인 필요 표시에 쓴다.
- 강조는 색을 새로 넣지 않고 **인디고의 진하기**로 나눈다.
  - 사용자가 행동할 곳: **진한 인디고**(600 채움, 800 글자)
  - 에이전트가 한 일: **옅은 인디고**(100 배경, 700 글자)
  - 링크·선택: 인디고 600 글자·선
- **빨강은 기능색이다.** 브랜드 색이 아니다. 마감 당일·마감 지남·오류에만 쓰고, 장식이나 강조로는 쓰지 않는다.
- 회색 스케일에는 색조를 넣지 않았다(채도 0). 인디고가 유일한 색이 되어야 눈에 띄기 때문이다.

### 3-2. 면적 비율 (주색 70 : 보조색 30)
| 비율 | 계열 | 쓰는 곳 |
|---|---|---|
| **70%** | 주색 (회색 스케일, 흰색 포함) | 페이지 배경, 카드, 모달, 여백, 글자, 테두리 |
| **30%** | 보조색 (인디고 스케일) | 사이드바, 채움 버튼, 링크, 선택 상태, 완료 체크, 진행 바, '자동' 배지, 확인 필요 배너 |

- 비율은 화면 면적으로 잰다. 30% 중 대부분은 사이드바가 차지한다. 본문 영역 안의 인디고는 버튼·배지·링크처럼 작은 요소로만 쓴다.
- 인디고로 **채운** 버튼은 화면(또는 카드)마다 **1개**만 쓴다. 두 번째 행동부터는 Secondary나 Text 버튼으로 한다.

### 3-5. 상태별 표현
| 상태 | 표현 |
|---|---|
| 확인 필요 (사용자 행동 필요) | `secondary-50` 배경, `secondary-200` 테두리, `secondary-800` 굵은 글자, `secondary-600` 경고 아이콘. 행동 버튼은 인디고 채움 |
| 자동 처리됨 | `secondary-100` 배경, `secondary-700` 글자, `secondary-500` 점 |
| 진행 중·할 일 같은 상태 필 | `primary-200` 배경, `primary-700` 글자 |
| 마감 당일·지남 | `error-600` 글자와 체크박스 테두리 |
| 완료 | `secondary-600`으로 채운 체크, 제목은 `primary-500` 취소선 |
| 저장·연결 성공 | 흰 표면에 `secondary-600` 체크 아이콘 + 문구 |
| 시스템 경고 (권한 미허용 등) | `primary-200` 배경, `primary-900` 글자, `secondary-600` 경고 아이콘 |
| 추출 실패 | `primary-600` 글자, `primary-400` 선 |

- '확인 필요'와 '자동'은 둘 다 인디고라서 **모양이 달라야** 한다. 확인 필요는 아이콘이 붙은 넓은 배너와 채움 버튼이고, 자동은 점이 붙은 작은 배지다.
- 상태는 색만으로 구분하지 않는다. **항상 아이콘이나 문구를 같이** 쓴다.

## 4. 컴포넌트

### 4-1. 기본값
- **모서리:** 카드 14px, 버튼 8px, 배지·필 999px
- **간격:** 4px 단위 (4 · 8 · 12 · 16 · 24 · 32 · 48)
- **카드:** 흰색 표면 + `primary-300` 1px 테두리. 그림자는 쓰지 않는다. 다른 앱 위에 뜨는 캡처 오버레이만 예외로 옅은 그림자를 둔다.

### 4-2. 버튼
| 종류 | 채움 | 글자 | 테두리 | 쓰는 곳 |
|---|---|---|---|---|
| Primary | `secondary-600`, hover `secondary-700` | 흰색 | 없음 | 화면(카드)마다 1개, 가장 중요한 행동 |
| Secondary | 흰색 | `primary-900` | `primary-300` | 두 번째 행동 |
| Text | 없음 | `secondary-600` | 없음 | 보기, 되돌리기 같은 가벼운 행동 |
| Quiet | 없음 | `primary-600` | 없음 | 닫기, 나중에 하기 |

- 라벨은 Pretendard 600이다.

### 4-3. 그 밖의 컴포넌트
- **사이드바:** `secondary-600` 배경이다.
  - 선택된 항목: 흰색 14% 덮개 + 왼쪽에 흰색 3px 표시선
  - 개수 배지: 흰색 원에 `secondary-700` 숫자
  - 보조 항목(설정): `secondary-100` 글자
- **'자동' 배지:** 어디에 있든 모양이 같다. `secondary-100` 배경, `secondary-200` 테두리, `secondary-700` 글자, 앞에 `secondary-500` 점.
- **확인 필요 배너:** 본문 폭을 꽉 채운다. `secondary-50` 배경, `secondary-200` 테두리, 왼쪽에 `secondary-600` 경고 아이콘, 오른쪽에 Text 버튼 "보기".
- **체크박스:** 원형이다. 테두리 색으로 마감 상태를 보여준다.
  - 마감 당일·지남: `error-600`
  - 예정: `secondary-600`
  - 여유: `primary-400`
  - 완료: `secondary-600`으로 채우고 흰 체크
- **진행 바:** 트랙은 `primary-200`, 채움은 `secondary-600`이다. 되돌리기 타이머 바는 `secondary-300`이다.
- **확신도 분기 표시:** 확신 높음은 `secondary-300` 선 + '자동' 배지, 확신 낮음은 `secondary-600` 선 + 인디고 채움 필, 추출 실패는 `primary-400` 선 + 회색 필.

## 5. 알림과 오버레이

### 5-1. 어디로 알리나
| 상황 | 채널 | 디자인 범위 |
|---|---|---|
| 캡처 직후 결과 (분석 중 → 자동 반영 / 확인 필요) | **캡처 오버레이** (Tide가 그린다) | 전부 이 스펙의 컴포넌트와 색으로 그린다 |
| 사용자가 캡처하지 않았는데 에이전트가 바꾼 것 | **OS 알림** | 문구, 앱 아이콘, 버튼, 이미지만 정한다 |
| 확인 필요 오버레이를 확인하지 않고 닫음, 결과가 나올 때 화면이 잠겨 있음 | OS 알림 | 같음 |
| 웹 대시보드 | 브라우저 알림 | OS 알림과 같다 |

- 같은 건을 오버레이와 OS 알림으로 **두 번 알리지 않는다.**
- OS 알림을 흉내 낸 커스텀 창은 만들지 않는다.

### 5-2. OS 알림에서 브랜드를 드러내는 법
OS 알림은 레이아웃, 폰트, 색을 시스템이 정한다. 브랜드는 아래 네 가지로만 드러낸다.
- **앱 아이콘:** 알림에서 유일한 시각 요소다. 작은 크기용 앱 아이콘이 들어간다.
- **문구:** UI와 같은 해요체로, 결과를 먼저 쓴다. 제목은 한 줄(한글 20자 안팎)이다.
- **'자동' 표시:** 배지를 넣을 수 없어서 출처 줄에 "캡처에서 자동 생성", "자동 반영"이라고 쓴다.
- **버튼:** 최대 2개. 주 행동을 첫 번째에 둔다. 알림 본문을 누르면 첫 번째 버튼과 같게 동작한다.

### 5-3. 알림 종류
| 종류 | 제목 | 본문 | 출처 줄 | 이미지 | 버튼 | 묶음 |
|---|---|---|---|---|---|---|
| 1건 추가 | 태스크 1건을 추가했어요 | {태스크 이름} · {마감} | 캡처에서 자동 생성 | 없음 | 보기 · 되돌리기 | 5분 묶음의 첫 건 |
| 묶음 | 태스크 {n}건이 반영됐어요 | 추가 {a}건 · 상태 변경 {b}건 | 자동 반영 · 대시보드에서 하나씩 되돌릴 수 있어요 | 없음 | 모두 보기 | 같은 알림을 바꿔 끼운다 |
| 확인 필요 | 확인이 필요한 캡처가 있어요 | 캡처를 '확인 필요'에 보관했어요 | 없음 | 캡처 썸네일 | 지금 확인 · 나중에 | **묶지 않는다** |

- 태스크 이름이 30자를 넘으면 말줄임표로 줄인다.

### 5-4. 캡처 오버레이
- 캡처한 화면의 오른쪽 아래, 가장자리에서 16px 떨어진 곳에 뜬다. 카드 폭은 320px이다.
- 같은 자리에서 세 단계로 바뀐다.
  | 단계 | 내용 | 버튼 | 닫힘 |
  |---|---|---|---|
  | ① 분석 중 | 캡처 썸네일 + 진행 바 | 없음 | 최대 10초, 넘으면 ③ |
  | ② 자동 반영됨 | '자동' 배지 + 태스크 + 타이머 바 | Text "되돌리기" · Primary "보기" | 6초 뒤 (마우스를 올리면 멈춤) |
  | ③ 확인 필요·실패 | 경고 아이콘 + 안내 문구 | Quiet "닫기" · Primary "지금 확인" | 사용자가 닫을 때까지 |
- 카드마다 Primary 버튼은 하나다.

## 6. 아이콘
- 24px 그리드, 선 굵기 1.8, 끝과 모서리는 둥글게 그린다. 색은 글자색을 따른다.
- 12종: `check-circle`, `status-ring`, `alert`, `auto`, `capture`, `image`, `undo`, `plus`, `bell`, `today`, `inbox`, `settings`
- 아이콘 색은 `primary-600`(기본), `primary-900`(선택), `secondary-600`(브랜드·확인 필요), `error-600`(오류) 네 가지만 쓴다.
