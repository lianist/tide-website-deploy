# 보류(hold-out) 세트 — 튜닝에 쓰지 않는다

평가 세트(`../create/`)로 프롬프트를 고치다 보면 **그 11장에만 맞는 프롬프트**가 된다. 이 폴더는 그걸 잡으려고 둔다.

- **프롬프트를 고칠 때 이 폴더의 결과를 보지 않는다.** 후보를 확정한 뒤에만 채점하고, 점수가 평가 세트보다 크게 낮으면 과적합으로 본다.
- 실행: `GRADE_SET=holdout npm run grade -- --repeat-each=3`
- 이미지는 **가상 화면**이다. HTML(메신저·메일·메모·풍경)을 Playwright로 렌더링해 찍었다(L-P0-08, 2026-09-22). 실명·연락처가 없고, 태그(회사·동아리·가족)와 도메인을 평가 세트와 겹치지 않게 골랐다. 프롬프트의 예시에 나오는 대상(보고서·회의록·참가비 등)도 피했다.
- 기대 결과는 **채점 전에** 적었다. 결과를 보고 고치지 않는다.
- 가상 화면은 실제 캡처보다 깔끔해서 점수가 후하게 나올 수 있다. 이 세트가 잡는 것은 "평가 세트 고유의 표현에 기댄 프롬프트"이지 OCR 난도가 아니다.
- 누수 가드(`e2e/agent-create.spec.ts`)는 이 세트의 정답 조각도 프롬프트에 없는지 본다.
