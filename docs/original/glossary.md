| 이름 | 영어 | 설명 |
| --- | --- | --- |
| 태스크 | TASK | 태스크란, 본 서비스가 생성, 수정 및 관리하는, 유저가 해야 하는 업무이다. |
| 맥락 | CONTEXT | 맥락이란, 보다 정확한 태스크 관리를 위한, 유저의 캡쳐 정보 및 본 서비스가 유지하고 있는 유저에 대한 태스크 정보의 집합이다. |
| 캡쳐 | SCREENSHOT | 캡쳐란, 유저가 유저의 화면에서 본 서비스로 어떠한 정보를 넘기기 위해 활용하는 수단으로, 화면의 일부에 대한 스크린샷이다. |
| 상태 | STATUS | 상태란, 어떠한 유저의 태스크의 진행상황 및 비고사항을 포함하는 정보이다. |
| 에이전트 | AGENT | 에이전트란, 유저의 캡쳐를 바탕으로 태스크 관련 정보(신규 내용, 수정사항 등)를 추출하는 시스템이다. |
| 대시보드 | DASHBOARD | 대시보드란, 유저의 태스크를 모아둔 웹사이트 또는 웹뷰 페이지이다. |
| 푸쉬 | PUSH | 푸쉬란, 유저가 캡쳐를 에이전트가 분석 완료했을 때 유저에게 주는 알림이다. |
| 태그 | TAG | 태그란, 여러 태스크 들이 공유할 수 있는 하나의 속성(e.g., 소속된 프로젝트 등)이다. |
